## Контекст проекта

**Задача:** страница частного предложения займа — ₽1,5 млн под 15–20% годовых на 18 месяцев, под запуск студии AI-продуктов (сервисы: заказная разработка + SMM-подписка; флагманы: AURA, MyBrain; платформы 2027: MyUniverse, Meridian). Аудитория: частные инвесторы — владельцы бизнесов и топ-менеджеры из личного нетворка, 45+, финансово грамотные. Канал: личная ссылка после телефонного звонка.

**Инфраструктура:** GitHub Pages, домен rovensky.ru (переведён с Tilda в этой же работе), один HTML-файл без внешних зависимостей. Дизайн-система «бумага/чернила»: фон #F3EEE5, чернила #1B1A17, янтарь #E0A458, серифы Fraunces + моно IBM Plex Mono.

### Скорость и доступность без VPN (июль 2026)
Жалоба: страница почти не открывается, особенно без VPN. Причина — блокирующая загрузка Google Fonts (fonts.googleapis.com), недоступного из РФ без VPN. Побочно выяснилось: **Fraunces не имеет кириллического набора вообще** — все русские заголовки рендерились подстановкой Georgia, а ~100 КБ шрифта грузились впустую.
Решение: серифом стал **Playfair Display** (настоящая кириллица, тот же издательский контраст), все шрифты перенесены в репозиторий (`/fonts`, latin+cyrillic, 195 КБ, кэшируются); Inter заменён на системный шрифт (0 КБ); удалены все preconnect и внешние стили. Обе страницы делают **ноль внешних запросов** при загрузке; архивная v1 тоже отвязана. Проверено с полностью заблокированной внешней сетью: загрузка 0,4 с, вёрстка и интерактив целы.

### Доступность из РФ (август 2026) — РЕШЕНО
Симптом: страница не открывается с телефона (мобильный интернет), медленно с десктопа. Диагностика: домен rovensky.ru проксируется через **Cloudflare** (A-записи 185.199.108–111.153 верные, но со статусом Proxied) — Cloudflare в РФ у мобильных операторов деградирует. Проверка прямого адреса `x79628848009-dot.github.io` — **тоже не открывается**, то есть оператор режет и сам GitHub Pages.
**Решение:** в Cloudflare все записи `rovensky.ru` (4×A) и `www` переключены с «Proxied» на «DNS only» — Cloudflare остался только DNS-провайдером, трафик идёт напрямую на GitHub Pages (185.199.108–111.153). GitHub выпустил свой сертификат, «DNS check successful», Enforce HTTPS включён. **Проверено с мобильного интернета — страница открывается.**
Почему это сработало, хотя `github.io` у оператора не открывался: фильтрация идёт по имени домена в запросе, а не по IP. Обращение к тем же серверам под именем `rovensky.ru` фильтр пропускает.
Дополнительно как страховка: **автономная сборка** `offline/rovensky-pre-seed.html` — один файл 369 КБ со встроенными шрифтами и иконками, ноль внешних запросов, открывается без интернета; можно отправлять инвесторам файлом в Telegram/почтой.
**На будущее:** не включать проксирование Cloudflare для этого домена. У `mybrain.rovensky.ru` статус Proxied сохранён и он ведёт на Vercel — этот адрес из РФ, вероятно, недоступен; разобрать отдельно.

Тап по любой звезде — описание терминальной строкой. Автономная сборка обновлена.

### Затор публикации GitHub Pages (6 августа 2026)
После пересоздания custom domain в настройках Pages (Remove → добавить заново) очередь деплоя заклинило: сборка проходит успешно, а шаг публикации висит в `deployment_queued` и падает по таймауту. Запуск #34 застрял в статусе queued и, судя по поведению, держит блокировку окружения `github-pages`; GitHub отказывается отменять его через API («Cannot cancel a workflow re-run that has not yet queued»). Запуски #35 и #36 (с созвездием) по той же причине не публикуются — сайт отдаёт предыдущую версию.
**Лечится вручную:** Actions → застрявший запуск → Cancel workflow; либо Settings → Pages → Unpublish site → заново выбрать Source (Deploy from a branch · main · /root) → Save.
