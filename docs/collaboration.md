# Как ведётся работа над проектом

Над страницей работают два помощника Claude в разных ролях. Правила ниже — чтобы не мешать друг другу.

## Роли

**Claude в веб-версии (claude.ai) — обсуждение.**
Читает репозиторий, обсуждает с Михаилом смыслы, тексты, структуру, стратегию, спорит и предлагает. Начинать стоит с `docs/context-brief.md` (весь контекст проекта) и `docs/worklog.md` (история решений).
**Не коммитит и не меняет файлы.** Итог обсуждения Михаил приносит в Claude Code словами или списком.

**Claude Code (эта среда) — исполнение.**
Вносит все правки в код, проверяет вёрстку на телефоне и десктопе, гоняет тесты, коммитит, публикует. Ведёт `docs/worklog.md`.

Причина разделения: если править файлы из двух мест одновременно, изменения затирают друг друга и время уходит на разбор конфликтов вместо работы.

## Где что лежит

| Путь | Что это |
|---|---|
| `pre-seed/index.html` | **Боевая версия.** Висит на rovensky.ru/pre-seed/, её видят инвесторы. Не трогать без решения Михаила. |
| `next/index.html` | **Черновик новой версии.** Здесь идёт вся работа. Красная плашка «Черновик» и приписка в заголовке — чтобы не спутать. |
| `docs/page-text/next.md` | **Текст черновика** — читаемая выгрузка без кода. Для обсуждения смыслов бери её, а не HTML (91 КБ кода съедают контекст). |
| `docs/page-text/live.md` | Текст боевой версии — для сравнения. |
| `docs/context-brief.md` | Полный контекст проекта: сделка, портфель, цифры, принципы, ограничения. |
| `docs/strategy-brief-2026-08.md` | **Актуальная стратегическая позиция (август 2026).** Снимок стратегического репозитория `mybrain`: что изменилось с июля, статусы продуктов по факту, экономика и — главное — расхождения между страницей займа и стратегическими документами. Читать вместе с `context-brief.md`: тот описывает июльскую позицию, этот — отличия от неё. |
| `docs/worklog.md` | Хроника работы и принятых решений. |
| `audit/pre-seed-2026-07/` | Аудит семи агентов, вердикт арбитра, бэклог, речь к питчу. |
| `offline/` | Автономная сборка страницы одним файлом (работает без интернета). |
| `pre-seed/v1/` | Архив первой версии. |

Выгрузки текста обновляются автоматически: Claude Code запускает `node tools/export-text.mjs` после каждой правки страницы, раскрывая все скрытые блоки.

**Инварианты целостности черновика** (проверка: `node tools/check-invariants.mjs`, Claude Code гоняет после каждой правки продуктов):
1. Каждый продукт (AURA, MyBrain, SMM Engine, MyUniverse, Meridian) представлен во всех местах, где представлены его соседи: карта портфеля, карточка, разбор «подробнее» (кроме SMM — он раскрыт в источниках возврата), созвездие (кроме SMM).
2. Статусы — только из словаря: тестируется / строится / проект / ежедневная практика; один продукт — один статус во всех местах.
3. Элементы амбиции (флагманы, платформы) не сжимаются до сносок ради экономии слов — это отдельный принцип Михаила.

## Публикация новой версии

Когда Михаил решит, что черновик готов: снять плашку черновика, скопировать `next/index.html` поверх `pre-seed/index.html`, пересобрать автономную версию, опубликовать. Делает Claude Code.

## Открытый пункт по безопасности

Репозиторий сейчас **публичный**, а в нём лежат материалы, которые инвестору видеть не следует: разносы аудита, речь с ответами на жёсткие вопросы, бэклог с непринятыми решениями по ставке. Михаил планирует оплатить GitHub Pro и сделать репозиторий приватным. До этого момента не добавлять в репозиторий новых чувствительных материалов (переписку с инвесторами, имена, документы, суммы по конкретным людям).
