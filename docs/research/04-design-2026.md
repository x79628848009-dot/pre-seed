# Веб-дизайн «на миллиард» — 2026

## Палитры после бежевого
Кремово-бежевый «Claude-стиль» официально отработан — 2026 идёт в четырёх направлениях:

1. **Тёмная роскошь (Mercury-стиль)**: не чистый чёрный, а «мягкие тёмные» — charcoal `#1A1A1E`, тёплый off-black `#141210`, deep navy `#0B1120` + один металлический/тёплый акцент. Формула люкса: один глубокий якорь (black / navy / oxblood `#4A0E0E` / dark green) + минимум цветов, максимум точности.
2. **Тёмная ботаника**: forest green / deep teal — темнее и насыщеннее, чем sage 2022–24; сигнал «постоянство», не «wellness».
3. **Электрический акцент на тёмном**: chartreuse/wasabi (~`#C6D92E`), неоновые 1px-бордеры на тёмном фоне («tactile brutalism» — резкая геометрия вместо блюр-теней).
4. **Heritage-fintech (Plaid)**: эстетика банкноты — гильошированные узоры, гравюрные иллюстрации, монохром + один акцент.

## Типографика
- Формула пары: один sans-«рабочий» + один display-«спикер». Огромный serif-заголовок стал главным героем обложки — «curvy serifs», serif-революция + тихий гротеск в тексте.
- Variable fonts — дефолт: один файл, оси weight/optical size/width + экспериментальные SOFT/WONK.
- Приём премиум-финансов: serif pull-quotes внутри sans-текста; **tabular figures** для цифр (колонки выравниваются).
- Кинетический текст: заголовки раскрываются хореографией по скроллу, реагируют на курсор.

## Глубина и фактура
- **Grain/noise поверх всего** — низкоопачный SVG-noise как маркер «сделано человеком» (анти-AI-slop).
- **Dark glassmorphism v2**: несколько слоёв глубины, динамический blur + за стеклом — «ambient orbs» (глубокий фиолетовый, неоновый синий), gradient-borders.
- **Aurora-градиенты**: медленно плывущие WebGL/shader-градиенты в hero (Stripe и Vercel — «золотой стандарт gradient craft»).
- 1px solid бордеры вместо теней — «engineered precision»; Vercel — blueprint-grid эстетика (видимая сетка-чертёж).

## Motion
- Linear — эталон: «кинематографично тёмный», GPU-градиенты, продукт-демо, работающее прямо в браузере.
- Stripe: hero-градиент медленно меняет цвета при скролле.
- Анимируют: заголовки (scroll-reveal), градиентный фон (shader), микро-интеракции на hover, живые превью кода/продукта. Bento-grids и WebGL-шейдеры уже commodity — недостаточны сами по себе.
- OpenAI (Studio Dumbar): математические сетки + motion-led формы.

## Обложки лучших
Первый экран: гигантский display-заголовок (типографика = архитектура интерфейса), реальный продукт (живое демо/скриншот, не иллюстрация), медленный атмосферный градиент за контентом, один CTA. Anthropic — намеренная сдержанность и ясность; Mercury — «люкс-бренд, а не банк»: muted-палитра, editorial-фото из мира моды, щедрый воздух. Тёмные продукт-секции контрастируют со светлыми editorial-блоками.

## Антиприёмы 2026 (стыдно)
- **Indigo-фиолетовый градиент + Inter + 3 скруглённые карточки в ряд** — главный fingerprint AI-slop.
- Цветная 3–4px полоска слева на карточке — «самый надёжный AI-tell».
- rounded-2xl + shadow-lg на каждой поверхности, иконка-в-скруглённом-квадрате, emoji-буллеты, дефолтный shadcn-zinc, копирайт «Elevate your…».
- Рефлекторный глассморфизм без цели; blurred drop-shadows (вместо них 1px-геометрия); чистый #000; кремово-бежевый минимализм; «полированная однородность» — всё, что выглядит сгенерированным.
